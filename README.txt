MYQRSITE - source code

Files:
- index.html: page structure and Tailwind configuration
- css/style.css: custom CSS styles
- js/script.js: interactive page behavior

Run:
1. Extract this folder.
2. Open it in VS Code.
3. Open index.html with Live Server.

Notes:
- Tailwind CSS, Google Fonts, Lucide icons and QRCode.js load from CDNs, so an internet connection is needed.
- Some buttons/forms are demo interactions and show sample notifications; they are not connected to a production backend.

Update: The pricing section, pricing navigation links, pricing calculator, and plan-selection demo have been removed. Calls to action now direct visitors to the QR demo.
